# PixelKit

Сучасний Windows GUI для пакетного стиснення, зміни розміру та конвертації зображень через ImageMagick.

## Швидкий старт

1. Завантаж `outputs/PixelKit-Setup.exe`.
2. Запусти інсталятор.
3. PixelKit створить ярлик на робочому столі та в меню «Пуск».

## Можливості

- пакетна обробка файлів і цілих папок;
- зміна розміру за шириною/висотою або по довшій стороні;
- стиснення та конвертація JPG, PNG, WEBP, AVIF, GIF, BMP, TIFF;
- видалення метаданих;
- drag-and-drop і HiDPI-friendly інтерфейс.

Повний опис і запуск із вихідних файлів: [outputs/README.md](outputs/README.md).
